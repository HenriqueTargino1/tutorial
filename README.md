# TaskList

Um pequeno gerenciador de tarefas desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar tarefas.
- Marcar tarefas como concluídas clicando nelas.
- Adicionar tarefas pressionando Enter.
- Interface responsiva.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
